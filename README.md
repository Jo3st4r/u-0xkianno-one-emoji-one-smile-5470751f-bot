Exactly one emoji — the one most likely to make a stranger smile —
built for the [make.fun bounty](https://make.fun/bounty/u-0xkianno-one-emoji-one-smile-5470751f).

## The emoji

> 🫶

Two hands shaping a heart: warmth a stranger reads at a glance.
Kind, friendly, chosen — not the first smiley that comes to mind —
and it works coming from someone unknown, with no intimacy,
sarcasm or flirtation that could read oddly from a stranger.

## Run it

```sh
python3 main.py   # writes /output/entry.txt
```
